## Start with a Branch

Create a migration branch and keep a working copy of your current configuration.

## Adopt the Theme Incrementally

Add the theme, then update configuration, content front matter, images,
and custom templates one area at a time.
Compare the generated URLs before publishing.

## Preserve URLs

Keep existing permalink rules where possible.
Add redirects or aliases for changed public paths
so readers and search engines can still reach older posts.
