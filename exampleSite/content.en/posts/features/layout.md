## Main Areas

SeoTax uses a sidebar for profile and navigation, a central reading column,
and a table of contents when space allows.

## Responsive Behavior

On narrower screens, the sidebar and table of contents become overlays.
Post thumbnails, lists, and image blocks adapt to the available width.

## Page Types

The theme provides layouts for the home list, single posts,
search, category terms, and tag terms.
