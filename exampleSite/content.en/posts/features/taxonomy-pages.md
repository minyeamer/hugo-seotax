## Categories

SeoTax displays categories as a two-level tree with post counts
and quick links to filtered search results.

## Tags

Tag chips open the dynamic search page.
This lets readers combine tags instead of visiting one static page per term.

## Static Term Pages

Use `disableKinds: ["term"]` when you want the search page
to be the primary taxonomy experience.
