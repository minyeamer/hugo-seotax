## What Is SeoTax?

**SeoTax** brings search, categories, and tags together
so readers can find posts without hopping between a large collection of taxonomy pages.

Hugo keeps sites fast and straightforward,
but a site with many tags can also create many static term pages.
SeoTax uses one search page and client-side filters to keep navigation focused.

## Highlights

- Fuse.js search with category and tag filters
- Parent and child category navigation
- Client-side interface translations and dark mode
- Code blocks with line numbers, copy controls, and language labels
- Image dimensions to reduce layout shift
