## 두 가지 다국어

SeoTax에는 다국어와 관련된 개념이 두 가지 있습니다.

| 구분 | 역할 |
|---|---|
| Hugo multilingual | 글 자체를 언어별로 분리 |
| SeoTax client i18n | 메뉴, 버튼, 날짜 같은 UI 번역 |

글 내용을 여러 언어로 번역하려면 Hugo multilingual을 사용합니다.
UI 라벨만 바꾸고 싶다면 SeoTax의 클라이언트 i18n이 자동으로 동작합니다.

## 클라이언트 i18n의 장점

- 페이지 이동 없이 언어 변경
- URL 변경 없음
- 브라우저 언어 자동 감지
- 사용자가 선택한 언어 저장
- UI 텍스트, 속성, 날짜 형식 변경

## 번역 파일

번역 파일은 테마의 `i18n/` 폴더에 있습니다.

```text
themes/seotax/i18n/
  en.yaml
  ko.yaml
  ja.yaml
  ...
```

새 언어를 추가하려면 같은 형식의 YAML 파일을 추가합니다.

```yaml
- id: "search.action.label"
  translation: "검색"
```

## 설정

일반적으로 별도 설정이 필요 없습니다. 번역 파일 위치를 직접 지정하고 싶을 때만 아래 값을 사용합니다.

```yaml
params:
  i18nDir: "themes/seotax/i18n"
```
