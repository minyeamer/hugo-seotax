## 데스크톱 구조

SeoTax는 넓은 화면에서 3단 구조를 사용합니다.

| 위치 | 역할 |
|---|---|
| 왼쪽 | 프로필, 검색, 카테고리, 최신글 |
| 가운데 | 글 목록 또는 본문 |
| 오른쪽 | 목차 |

사이드바와 목차는 본문과 독립적으로 배치되어 긴 글에서도 탐색이 쉽습니다.

## 홈 화면

홈 화면은 글 목록을 카드처럼 나열합니다.
각 글에는 제목, 요약, 날짜, 카테고리, 태그, 이미지가 표시됩니다.

카테고리와 태그는 단순 장식이 아니라 검색 페이지로 이어지는 필터 링크입니다.

## 글 상세 화면

글 상세에는 제목 위쪽에 카테고리가 표시되고, 제목 아래에는 날짜와 읽기 시간이 표시됩니다.

본문 아래에는 태그, 이전/다음 글, 댓글, 저작권 영역이 이어집니다.

## 모바일 구조

모바일에서는 본문을 먼저 읽기 좋게 단일 컬럼으로 표시합니다.
사이드바와 목차는 헤더 버튼으로 열 수 있는 오버레이가 됩니다.

검색창도 모바일 헤더에서 접근할 수 있어 작은 화면에서도 검색 진입점이 사라지지 않습니다.
