## 목록 페이지는 유지됩니다

`disableKinds: ["term"]`을 사용하면 개별 카테고리와 태그의 정적 페이지가 생성되지 않습니다.

하지만 전체 목록을 보여주는 아래 페이지는 계속 사용할 수 있습니다.

- `/categories/`
- `/tags/`

## 카테고리 페이지

카테고리는 부모와 자식의 2단계 트리로 표시됩니다.
각 카테고리에는 대표 글을 일부 보여주고, 더 많은 글은 검색 페이지에서 확인합니다.

```yaml
categories: ["Frontend", "Blog"]
```

## 태그 페이지

태그 페이지는 사이트의 모든 태그를 칩 형태로 보여줍니다.
칩을 클릭하면 해당 태그가 적용된 검색 결과로 이동합니다.

## 링크 흐름

글 목록, 글 상세, 사이드바, 카테고리 페이지, 태그 페이지가 모두 같은 검색 URL 규칙을 사용합니다.
덕분에 별도의 term 템플릿 없이도 일관된 탐색 경험을 제공합니다.
