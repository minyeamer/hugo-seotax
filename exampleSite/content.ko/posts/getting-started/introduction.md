## SeoTax 테마란?

**SeoTax**는 Hugo 블로그에서 글을 더 쉽게 찾고 분류할 수 있도록 검색, 카테고리, 태그 탐색을 한 화면에 모은 테마입니다.

Hugo는 정적 사이트 생성기라 빠르고 단순하지만,
태그와 카테고리가 많아질수록 각 항목마다 정적 페이지가 늘어납니다.
SeoTax 테마는 이 문제를 단일 검색 페이지와 JavaScript 필터로 줄입니다.

## 이런 블로그에 어울립니다

- 태그와 카테고리를 많이 쓰는 기술 블로그
- 시리즈 글이 많아 이전/다음 글 이동이 중요한 블로그
- 독자가 키워드, 카테고리, 태그로 글을 탐색하길 원하는 블로그
- 다크모드, 코드블럭, 댓글, SEO 기본값을 한 번에 갖추고 싶은 블로그

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 동적 검색 | Fuse.js 기반 검색과 카테고리/태그 필터 |
| 2단계 카테고리 | 부모/자식 카테고리 구조 |
| 클라이언트 i18n | 페이지 이동 없이 UI 언어 전환 |
| 다크모드 | 시스템 설정 감지와 수동 토글 |
| 코드블럭 | 줄 번호, 복사 버튼, 언어 라벨 |
| 성능 최적화 | 이미지 CLS 방지, 경량 아이콘 폰트 |
